# Tihar Bazaar — Web App

Nepal ka festival shopping website! 🪔

- 69 products (festive + electronics + mobile spare parts)
- Flipkart-style: ratings, discounts, price filters
- Cart + WhatsApp ordering
- Hindi / Nepali / English

## Run locally
Just open `index.html` in a browser. All 46 product photos are in `assets/`.

## Deploy (GitHub Pages)
Push to the `main` branch — GitHub Pages serves `index.html` automatically.
Custom domain: `tiharbazaar.com` (set via repo Settings → Pages → Custom domain).
